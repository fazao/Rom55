USDA Asset-Backed.

02 / Foundations

04 / Components

Buttons

Botões herdam DNA de interfaces terminais: radius 0, prefixo ■ em sky/gold, tipografia Michroma uppercase 10px com tracking 1.8px. Hover adiciona glow externo + ring interno. Transição padrão: 0.3s cubic-bezier(.4, 0, .2, 1).

05 / Components

Compare Cards

Padrão de cards "good vs bad" usado para confrontar o produto com concorrentes. A cor da borda + ring inset + glow externo definem polaridade: vermelho para problemas, sky para soluções. Cada item tem ícone-box compacto (18 × 18px).

⊖ Traditional Stablecoins

  • × Value exists outside the system — pegged to bank deposits off-chain
  • × Single-asset dependency — structurally fragile
  • × Value cannot grow — holding generates zero return
  • × No ecosystem loop — participants gain nothing from growth

△ With USDA

  • ✓ Real assets inside the system — gold reserves anchor the value foundation
  • ✓ Multi-asset pool — energy, minerals, tokenized equities continuously added
  • ✓ Value flows in continuously — not collateral-generated, but ecosystem-fueled
  • ✓ Ecosystem value return — every participant earns as the system grows

08 / Motion

Animations

Curva única para todo o sistema: cubic-bezier(.4, 0, .2, 1) (Material standard). Durações: .15s para feedback imediato e .3s para transições visíveis. Keyframes extraídos do site: spin, cms-shimmer, type (typewriter), blink (cursor), text-slide e ticker.
